## 一句话流程

```
游戏客户端 ──拆包──▶ bundle ──build_assembly.py──▶ assembly_<arena>.json（世界坐标三角面 + 相机 + 锚点）
                                        │
                                        ├──export_glb.py──▶ .glb ──▶ three.js 查看器
                                        │
                                        └──scan_px.py──▶ px_<arena>.json（点位：像素 / 角度 / 穿透链 / 阵位段数）
                                                             │
                                              ┌──────────────┼──────────────┐
                                        verify_px.py    audit_px.py    sim_charge.py
                                        （可信度）      （六项审计）   （战场轮换）
                                                             │
                                                       gen_*_page.py ──▶ 两个 HTML 页面
```

## 结论摘要

- 130 个判定点，分级 **S 3 / A 15 / B 35 / C 36 / D 41**；A 及以上 18 个可以直接照着打。
- 代码与几何都过了独立校验（往返误差 ≤0.03 px），**「不准」的原因是前提没写全**：
  - 只有 **22%** 的点在 5 个掩体下都能打 ≥2 段（换掩体被自家掩体挡住）
  - 像素坐标**只在 16:9 有效**（21:9 上边缘点漂 100~256 px）
  - 准星容错中位只有 **4.2 px**（纵向 2~4 px）
