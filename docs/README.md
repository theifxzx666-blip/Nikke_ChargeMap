## 章节归属（先看这个，别再看错一章）

`CampaignChapterTable` 的 `id` 只是主键，**真章节号是 `chapter` 字段**（`= chapter_id − 1`）。
用关卡剧本名反查最硬：

| 区域 | `chapter_id` | `chapter` | 剧本 | 章节 `field_id` | 显示章节 |
|---|---:|---:|---|---|---|
| 晶化城市森林 | 35 | 34 | `d_main_34_*` | `fcbg_cityforestcrystal_007` | **第 34 章** |
| 沼泽丛林 | 36 | 35 | `d_main_35_*` | `fcbg_swamplandjungle_001` | **第 35 章** |

35 章 Boss 是**圣甲虫**：关卡 `6035044`（`d_main_35_09_s`，`monster_id 13100101`，Hard 镜像 `7035044`，Story `8035009`）。

## 一句话流程

```
游戏客户端 ──拆包──▶ bundle ──build_assembly.py──▶ assembly_<arena>.json（世界坐标三角面 + 相机 + 锚点）
                                        │
                                        ├──export_glb.py──▶ .glb ──▶ three.js 查看器
                                        │
                                        └──scan_px.py──▶ px_<arena>.json（点位：像素 / 角度 / 穿透链 / 阵位段数）
                                                             │
                                              ┌──────────────┼──────────────┐
                                        verify_px.py    audit_px.py    sim_charge.py
                                        （可信度）      （六项审计）   （战场轮换）
                                                             │
                                                       gen_*_page.py ──▶ 两个 HTML 页面
```

换章节时，`build_assembly.py` 这一步有三处必须现场判断（压缩网格 / 无 Camera / `*_col` 过滤），
另有一处渲染判断（alpha 走 MASK 还是 BLEND），见 `04-跨章节对照.md` §3。

## 结论摘要

### 第 35 章 · 沼泽丛林（63 点）

- `z=zmin` bug 修掉后几何涨 4 倍（001：15,276 → 62,070 三角面），旧值 130 个点是**虚高**，正确值 **63**。
- 分级 **S 3 / A 2 / B 19 / C 14 / D 25**；其中 001~005 常规图占 57 点，`bbg008` 0 点、`bbg009` 6 点。
- 圣甲虫 boss：`bbg008` 是开阔水面 + 中央植被岛，受击体 28 件却没有一条 ≥2 段的共线 → **只能打敌人本体充能**；
  `bbg009` 山脊 + 枯树 + 浅水，74 件受击体、6 个达标点，最高 4 段 `px(242,349)`（50.2m，五阵位全可用）。

### 第 34 章 · 晶化城市森林（120 点）

- 分级 **S 4 / A 7 / B 32 / C 17 / D 60**，锥宽中位 **2.8px**，五图池子 **132%~154%**。
- 段数与稳定性互斥：受击体排成 45~55m 细长队列，共线走廊在屏幕上只有 1~2px 宽，
  所以每图给双榜（段数冠军 / 实战冠军）。

### 母鲸领域（3 套，旧几何未回归）

仍是 `z=zmin` 修复前的点位与分级（本地无 `sbg_mw*` 原始 bundle），**不要和 34/35 章横向比较**。

城市林地（第 47/48 章）三套**不能套用上面的分级**：可破坏物只有 10~30 件、`hard` 各只有 1 件，
池子/需求比大概率 < 30%，点位精度也只有 ±1° 级。详见 `04-跨章节对照.md` §6。
