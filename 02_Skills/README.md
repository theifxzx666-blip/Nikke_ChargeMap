## 两者的关系

```
S-MAP   ── 主线：一次把一个区域做完（721 步，串行依赖）
   │
   └─ 第 ③④⑤⑥ 步需要按阵位铺开 ──▶  S-VIEW（并行批处理 + 分层渲染 + 真机验收）
```

**先 S-MAP 跑通单阵位（`cover_3`），再用 S-VIEW 铺 5 个阵位。**
反过来会浪费：单阵位都不通就直接跑批，35 组一起错。

## 维护约定

- 每次踩到**新坑**，先判断归属：算法/几何 → S-MAP；渲染/交互/阵位 → S-VIEW。
- 技能文档里的数字**必须是从 `导出/` 现算的**，不许手抄历史值。数字会随几何修复失效
  （2026-10-27 就因为 `z=zmin` 修复，35 章从 130 点变 63 点）。
- 改完技能，同步 `..\AGENTS.md` 的技能表状态。
